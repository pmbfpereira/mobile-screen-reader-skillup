# Mobile Screen Reader Skill-up

Ready to publish as a static site, including GitHub Enterprise Pages.

## Files

- `index.html` — landing page for the workshop
- `01_navigation_semantics.html` — Exercise 1
- `02_interaction_focus.html` — Exercise 2

## Exercise 1 — Navigation & semantics

Covers:
- headings
- accessible names
- reading order
- grouping
- contextual action labels
- decorative vs meaningful content

## Exercise 2 — Interaction & focus

Covers:
- form labels
- validation errors
- dialog / bottom-sheet semantics
- focus management
- dynamic announcements
- web-content transition

## Suggested use

Open the landing page on a phone and use:

- iOS: VoiceOver + Safari
- Android: TalkBack + Chrome

Ask participants to try the bad version first using only the screen reader, discuss what made the task difficult, then switch to the improved version.

These are web accessibility exercises running on mobile screen readers. They are not simulations of native iOS/Android accessibility APIs.

## GitHub Enterprise Pages

Upload these files to the repository root. Configure GitHub Pages to publish from that branch/folder. The site entry point is `index.html`.
